# 🚀 Sobre Mim

Sou **Analista de Expansão** com atuação em **Data Analytics**, **Inteligência de Mercado** e **Automação de Processos**.

Minha trajetória profissional foi construída em diferentes segmentos, como varejo, distribuição e operações administrativas, proporcionando uma visão ampla dos processos de negócio e do comportamento do consumidor.

Atualmente atuo desenvolvendo estudos mercadológicos, análises de viabilidade comercial, modelagem de indicadores, automações em Python e suporte à tomada de decisão estratégica para expansão empresarial.

Tenho formação voltada tanto para gestão quanto para tecnologia, unindo visão de negócio com capacidade analítica para resolver problemas complexos utilizando dados.

Meu objetivo é evoluir para posições cada vez mais especializadas em **Data Analytics** e **Data Science**, aplicando tecnologia para gerar impacto real nas organizações.
